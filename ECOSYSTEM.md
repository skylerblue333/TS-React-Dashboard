# Ecosystem Integration

**Role:** shared frontend/dashboard surface.

**Foundation:** React/TypeScript with the repository's existing linting, formatting, tests, Docker, and package management. Existing UI work must be preserved.

**Consumes:** typed API contracts from canonical platform services.

**Provides:** reusable dashboard/page components and product-facing composition.

**Production requirements:** route-level error boundaries, loading/empty states, accessibility, security headers, API contract tests, deterministic builds, and performance budgets.
